A military-themed WooCommerce WordPress theme for Comic Armor - Premium Comic Book Mailing Protection.

== Description ==

Comic Armor is a premium WordPress theme designed specifically for the Comic Armor brand - providing military-grade protection for comic book shipping.

= Features =

* USMC Digital Camo inspired design
* Full WooCommerce integration
* Hero slider with video support
* Customizer options for easy configuration
* Responsive design for all devices
* Product showcase section
* How It Works section
* Testimonials slider
* Call-to-action sections
* Custom 404 page
* SEO optimized

= Theme Customization =

The theme includes extensive customization options:

1. **Hero Slider** - Configure up to 3 slides with custom images, titles, and video backgrounds
2. **About Section** - Customize the mission statement and statistics
3. **Social Links** - Add your social media profiles
4. **Promo Video** - Embed your YouTube/Vimeo promotional video

= WooCommerce =

This theme is designed to work seamlessly with WooCommerce:

* 4-column product grid
* Custom product badges (Sale, New, Featured)
* AJAX add to cart
* Custom checkout styling
* Trust badges on product pages

== Installation ==

1. Upload the theme folder to `/wp-content/themes/`
2. Activate the theme through the 'Themes' menu in WordPress
3. Install and activate WooCommerce plugin (recommended)
4. Go to Appearance > Customize to configure the theme
